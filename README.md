# Start Junior - Frontend Darslari

3 oylik bepul frontend dasturlash kursi. Uzbek tilida, video darslar bilan.

## 🚀 Kurs Haqida

Bu kurs 0 dan boshlab Junior Frontend Developer bo'lish uchun mo'ljallangan:

- **Davomiyligi**: 3 oy (12 hafta)
- **Narxi**: Bepul
- **Tili**: O'zbek
- **Texnologiyalar**: HTML, CSS, JavaScript, Node.js, Git

## 📚 Kurs Tarkibi

### 1-hafta: Start - VS Code & Tools
- VS Code o'rnatish va sozlash
- Brauzer DevTools bilan tanishish
- Fayl va papka tartibi
- Internet, hosting va frontend/backend farqi

### 2-3-hafta: HTML - Sahifa Skeleti
- Birinchi HTML sahifa
- Matn teglari va ro'yxatlar
- Linklar, rasmlar va fayl yo'llari
- Formalar va inputlar
- Jadvalar va ma'lumotlar
- Semantik HTML va accessibility
- HTML5 yangi teglar
- HTML mini loyiha: portfolio skeleti

### 4-5-hafta: CSS - Dizayn va Layout
- CSS ulash va selektorlar
- Box model va spacing tizimi
- Flexbox bilan navbar va kartalar
- CSS Grid bilan sahifa bo'limlari
- Responsive design va media query
- CSS mini loyiha: portfolio dizayni

### 6-8-hafta: JavaScript - Interaktivlik
- O'zgaruvchilar va data turlari
- Shartlar va sikllar
- Funksiyalar va clean code
- DOM bilan HTML boshqarish
- Events va forma validatsiya
- LocalStorage va JSON
- Fetch API bilan serverdan ma'lumot olish
- Array va Object metodlari
- ES6 Classes va OOP asoslari
- JavaScript Modules va import/export
- Error handling va debugging
- JavaScript loyihasi: To-do app

### 9-10-hafta: Node.js Backend - API va Account
- Node.js nima va server ishga tushirish
- REST API endpointlar
- Account yaratish va validatsiya
- Frontendni backend API ga ulash
- Backend clean code va xavfsizlik asoslari

### 11-12-hafta: Git va GitHub - Yakuniy Ish Oqimi
- Git o'rnatish va birinchi commit
- GitHub account va remote repo
- Branch, merge va conflict
- Pull Request va code review
- GitHub Pages bilan bepul deploy
- Final loyiha: Junior portfolio va README

## 🛠 Ishga Tushirish

### Frontend (Angular)
```bash
npm install
ng serve --port 4200
```
Brauzerda: http://localhost:4200

### Backend (Node.js)
```bash
cd server
npm install
node index.js
```
API: http://localhost:3000
